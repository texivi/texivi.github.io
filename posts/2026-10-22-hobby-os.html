A hobby OS is allowed to be impractical

Nobody needs my operating system, and I don't pretend otherwise. It runs in QEMU, it has no networking, and you can't get work done in it.

I think that is fine, and that more people should write something nobody needs. A project that has to be useful has to be careful, and a careful project rarely tries a strange idea. Mine can have a shell where numbers go past infinity because nobody will lose a day of work to it.

A real operating system has to keep working for someone. Mine has no such users, so I can try things.
