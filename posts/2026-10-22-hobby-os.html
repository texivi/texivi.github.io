A hobby OS is allowed to be impractical

Nobody needs my operating system, and I don't pretend they do. It runs in QEMU, it has no networking, and you can't get work done in it.

I think that is fine, and that more people should write something nobody needs. A project that has to be useful has to be careful, and a careful project doesn't try the strange idea. Mine can have a shell where numbers go past infinity, because nobody will lose a day of work to it.

The line between a hobby OS and a real one is not size or skill. It is that a real one has to keep working for somebody. I don't have anyone to keep working for, and that is why I can try things.
