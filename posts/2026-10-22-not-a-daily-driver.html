Not a daily driver

My operating system is an experimental hobby project. I don't use it for work, and it is not meant to replace anything.

I use Linux every day. It is amazing. I run Exherbo, and I write for Linux too: TSWM, my window manager, is a Linux project. Building my own system is not a statement that Linux got it wrong. Linux solves a different problem, and solves it better than I could.

I build it to find out what an operating system is when one person decides every part of it.
