Subverge / Handbook

Features

  • Shell. The prompt runs omega, a postfix language. Commands and programs are written in the same language, and so are the programs that ship with the system.
  • JIT. A quote is compiled to x86-64 machine code the second time it runs, and xray disassembles the result (JIT, dis).
  • Transactions. When a word fails, the whole line is undone. back undoes up to 64 lines that succeeded (transactions, back).
  • Integers. A result that overflows 64 bits becomes a bignum of up to 2^65536, in interpreted and in compiled code (bignums).
  • Infinity. omega and aleph0 are values that add, multiply and compare like other numbers (ordinals, cardinals, infinity).
  • Ring 0. All code runs in ring 0. peek, poke, in, out, cpuid and pci reach memory, I/O ports and the PCI bus (smarties).
  • Screen. The text screen is 80 by 25. A 640 by 480 graphics mode is available for drawing, with full-colour bitmaps and a JPEG decoder for the built-in pictures (screen, pictures).
  • Mouse. A PS/2 mouse is shown as an inverted cell on the text screen. It switches tabs from the top bar and follows links in the viewer (mouse).
  • Help. The kernel contains hyperlinked pages. docs and "name" doc open them in a pager, lines of code on a page can be selected and run, and every word has a page (help).
  • Tabs. Four shells run under a preemptive scheduler. Each has it is own stack and definitions. F1 to F4 switch between them, and they can be shown side by side in windows (tabs, scheduler).
  • Keys. The prompt, the pager and the editor share their line editing keys, with M-x, help keys and bindings written in omega (keys).
  • phi. A tree of sets that holds named values, with a directory editor, dired (phi).
  • Editor. scrawl edits the programs in root. An edit takes effect only if it builds, so a broken edit cannot break the running system (scrawl, root).
  • Saving. An installed disk is written after every line, and it keeps each shell's world and the edits to root as omega source (saving).
  • Boot loader. Installed disks boot with their own loader. GRUB is used only on the ISO (boot).
  • Themes. The colour themes also change the logo that sys draws (themes, logos).
  • Sound. A PC speaker driver provides beep (screen).
  • Memory. A garbage collector manages omega's objects (gc).
  • Programs. tools, games and demos. The demo index lists all of them.

See design and decisions for what the system leaves out, and the roadmap for what is planned.
