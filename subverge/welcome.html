Subverge / Handbook

Welcome to Subverge

Subverge is an x86-64 operating system for programming and experiments. It is not Linux. Everything runs in ring 0, the shell is a programming language, and the programs that come with it are written in that language and can be changed while the system runs. The kernel is called ordinal and the shell is called omega.

These pages and learn assume that you already program. They do not explain loops or variables. If you know Forth, begin with omega for Forth programmers.

The machine

Subverge runs in QEMU and has been tested only there. It boots from an ISO into an 80 by 25 text screen with four tabs. A PS/2 mouse works on that screen, and gfx starts a 640 by 480 graphics mode on the standard VGA display of QEMU (screen). docs opens these pages inside the system (help).

A live ISO saves nothing. install on a blank attached disk image keeps the work. An installed disk holds no files. It has fixed slots for the root units, the saved world of each shell and the boot code (disk layout), and it writes them after every line that succeeds (saving).

The language

The prompt runs omega, a postfix language related to Forth. The shell is also the compiler: a line is parsed and run, and compiled to x86-64 machine code the second time it runs (JIT). Programs and commands are written in the same language, so a command that is used often becomes a word with [ ... ] :name.

2 3 +
[ dup * ] :sq
7 sq

Every line is a transaction. When a word on the line fails, the whole line is undone, and back undoes up to 64 lines that succeeded (transactions). Raw writes to memory and I/O ports are outside this and cannot be undone.

Integers do not wrap. A result that does not fit in 64 bits becomes a bignum of up to 2^65536 (numbers, bignums). Infinity is a value as well: omega 1 + is a valid line and gives ω+1 (ordinals, cardinals).

Ring 0

peek and poke read and write any address, in and out talk to I/O ports, cpuid and pci read the CPU and the PCI bus, and xray disassembles the code the JIT made (memory, ports, dis). A bad write can stop the whole virtual machine. expectations covers this.

Four shells

Four shells run at the same time under a preemptive scheduler. Each has it is own stack, it's own definitions and its own screen, and they share only root, the heap and the hardware. F1 to F4 switch between them (tabs).

What to run first

The bundled programs cover most of what the system does. A program runs when its name is typed in a shell, and in the page viewer Enter on a link to one runs it at the prompt.

  • snake, tiles, pong and life
  • mandel, stars, rain and bounce
  • count, sorting and the other demos of infinity
  • calc, clock, stopwatch, todo and convert
  • top, irqmon and hexview, which read the machine
  • learn, a guided tour of the language in 47 lessons

The demo index lists every program and what it shows. Tools and games describe them one by one.
