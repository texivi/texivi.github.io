Subverge / Handbook

Flow

Conditions and loops are ordinary words that take quotes. Nothing about them is built into the syntax, so they can be passed around, wrapped and replaced like any other word.

Choices

cond [ then ] [ else ] if
cond [ then ] when
cond [ then ] unless

if runs one of two quotes. when runs its quote only if the condition is true, and unless only if it is false. The condition is a number: 0 is false and anything else is true, including every bignum. Comparisons leave 1 or 0 (numbers).

x 0 < [ "negative" ] [ "not negative" ] if say
n 100 > [ "big" say ] when
'startup defined? [ startup ] [ sys ] if

A branch that is not a quote is pushed instead of run, so short choices between values need no brackets:

x 0 < "negative" "not negative" if say

Nothing checks that both branches of an if leave the same number of values. If they do not, the problem shows up later, as a stack error in whatever comes next.

Chains of choices nest:

[ { n }
  n 0 < [ "negative" ] [
  n 0 = [ "zero" ] [ "positive" ] if ] if
] :sign

Loops

Word Effect
times n q -- runs q n times
for a b q -- runs q with each i from a to b-1 pushed
while test body -- runs body as long as test leaves a true value
do q -- runs q once 
3 [ "hi" say ] times            hi, three times
0 5 [ . ] for                   0 1 2 3 4
5 [ dup 0 > ] [ dup . 1 - ] while drop      5 4 3 2 1

times and for take 64-bit integers. A count of zero or less runs nothing, and for with b not above a runs nothing. for pushes the counter before each run and expects the quote to use it up. A quote that leaves it puts one more value on the stack every time.

while runs the test, takes the value it leaves, and runs the body if it is true. The test must be a quote: x 3 < [ ... ] while works out x 3 < once, before the loop starts, and gives a number as the test. That number is pushed every round and never changes. If the test leaves nothing, the loop fails.

Locals bound inside the test are gone by the time the body runs, because the locals of a quote end with it. Keep the state of a loop in locals that you bind outside the loop, and update them with ->:

0 { i }
[ i 10 < ] [ i . i 1 + ->i ] while

Leaving a loop early

Loops end through their condition. To stop a times or for early, write it as a while with a flag, which is how every bundled program runs its main loop:

1 { going }
[ going ] [
  key quit-key? [ 0 ->going ] when
] while

A word that fails also ends every loop at once, and the line with it, unless the loop is inside try (catching).

Walking lists

l [ f ] each          runs f on every item
l [ f ] map           collects f's result for every item
l [ f ] filter        keeps the items f approves

These are described with the other list words in quotes. On a string, each goes through the bytes.

Running code from data

do runs a quote held in a value:

[ 2 * ] { double }
21 double do .                  42

A local that holds a quote is pushed, not run, when its name appears, which is why do is needed here. A definition that holds a quote is run when its name appears.

eval parses a string and runs it:

"1 2 +" eval .                  3

Stopping

Ctrl-C interrupts any code that is running. The interpreter checks for it before every step, and times, for, while, each, map and filter check between rounds, so even a loop whose body is a single built-in word stops quickly. The line fails and is undone.

sleep, beep, key and waitkey wait without using the processor, and they also answer Ctrl-C.

Tracing

[ 1 2 + 4 * ] trace

trace runs a quote one step at a time. Before each step it prints the top of the stack and the item that is about to run, then waits for a key: Space takes one step, c runs the rest at full speed, and q, Escape or Ctrl-C stops with the error stopped. Words that the quote calls are traced too, so tracing a call into a large word steps through all of it.

Code that is being traced is never compiled, because compiled code cannot stop between items.

timeit, bench and watch time and repeat quotes (tools).

Recursion

A word can call itself:

[ { n } n 2 < [ n ] [ n 1 - fib n 2 - fib + ] if ] :fib
20 fib .                        6765

Every call nests, including calls in the last position of a quote, and nesting stops at 400 quotes with an error. Interpreted, each level of fib runs two quotes, its own body and a branch of if, so it reaches about 200 levels; compiled, the branch is inlined and only the body counts. Locals add a second limit of 256 live at once, which ends fib with too many local names before 400. Recursion suits trees and divide-and-conquer, whose depth grows slowly; long linear processes belong in a loop.

Speed

The JIT compiles if, when, unless, times, for and while into jumps when their quotes are written right in front of them and contain no locals or definitions:

0 1000000 [ 1 + ] times         compiled into a loop
[ 1 + ] { body } 0 1000000 body times     calls the body each round

The second form still works, but every round goes through a call. For loops that run many times, keep the quotes literal and the values on the stack.
