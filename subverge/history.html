Subverge / Handbook

History

This page tells where Subverge came from: the ideas it took from TempleOS, the video that gave it infinite numbers, where it's names come from, and the list of releases.

TempleOS

Subverge started from TempleOS. Like TempleOS, it is shell is also its compiler, everything runs in ring 0, and one language is used for the whole system.

None of the code came from TempleOS. Its shell is a stack language rather than a C dialect, code is compiled the second time it runs rather than ahead of time, and each line is a transaction, so a typo in ring 0 does not take the system down. It also treats infinity as a value.

Counting past infinity

Subverge was also inspired by Vsauce's video How To Count Past Infinity. Ordinals and cardinals are values in omega because of it, and the kernel and the shell are named after ordinals: ordinal, and omega for ω. The ordinals and cardinals pages start with the same ideas as the video.

The name

I made up the word subverge from subvert and diverge, after the Latin sub-, "under", and vergere, "to bend" or "to turn".

subverge (verb): to turn away from an established norm in a way that deliberately undermines it; literally, to dip beneath an edge or surface.

subvergent (adjective): quietly, deliberately non-conforming beneath dominant conventions.

subvergence (noun): the act of subverging.

The kernel is called ordinal, the shell omega, and the editor scrawl.

Code

All of Subverge was written for it, in C, assembly and omega. The only outside code is GRUB, which boots the ISO.
