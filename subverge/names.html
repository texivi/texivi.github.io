Subverge / Handbook

Names

A "name" is what you call a word or a value, such as sq or dup. When a word runs, omega looks its name up. A name can come from four places: the locals of the quote that is running, the definitions you made in your tab, root, and the built-in words. This page shows how each kind of name is made and in what order omega searches them.

Definitions

[ dup * ] :sq
42 :answer

:name takes the top value and binds it to a name in your tab. Using the name runs the value if it is a quote, and pushes it if it is anything else. A definition belongs to the tab that made it and is part of the world of that tab. For a word that every tab can see, use root.

Symbols

A quote mark in front of a name turns it into a value. This is how words that work on other words receive them:

'sq see             the definition
'sq help            the help entry
'sq get             the quote itself
'sq defined?        1 or 0
"sq" >sym get       same as 'sq get

Lookup order

  1. bound locals
  2. your tab's definitions
  3. root
  4. built-in words

The first match wins, so [ 1 ] :dup changes dup in your tab only.

Redefining

If you bind a name that is already defined, the new definition replaces the old one, and every word that uses the name picks up the new version at once:

[ dup dup * * ] :cube
[ cube 1 + ] :cube+1
2 cube+1 .          9
[ 0 ] :cube
2 cube+1 .          1

cube+1 stores the name cube, not the code that cube had when cube+1 was defined. The name is looked up again every time cube+1 runs. This is called late binding, and it is why you can fix a helper word and have every word that calls it use the fix, without redefining them.

The same goes for root. A definition in your tab with the name of a root word replaces that word for everything that runs in your tab, including programs from root. If you define [ "me" ] :user, sys shows me@subverge in that tab only.

Forgetting

[ 2 ] :sq
4 sq .              2
'sq forget
4 sq .              16, root's sq again

forget removes only definitions made in your tab, and the words they hid show again. 'top forget without a definition of top in the tab fails, because the tab has no definition of it. To change root words, edit root.

back undoes a forget like any other line.

Looking at definitions

see prints a definition and marks root definitions with (root). words lists the definitions of your tab, and src gives the source of the root unit that defines a name.

'name edit edits a definition of your tab in scrawl. For root words, use 'name open.

Locals

[ { a b } a b - ] :diff
9 4 diff            5

{ a b } takes values off the stack into locals, in the order they are written, so a is 9.

->x assigns to the innermost local x if there is one. Otherwise it binds a new one that lasts until the quote or line it is in ends:

9 ->x x .           prints 9
x .                 fails on the next line

Use :x for a value that has to stay. At most 256 locals can be bound at the same time, which limits how deep recursion can go (flow).

Dynamic scoping

Locals are dynamically scoped, which means a word can see the locals of the words that called it:

[ n . ] :shown
[ { n } shown ] :caller
5 caller            prints 5

shown never binds n, but it runs while the binding of caller is still alive. This lets a helper word read the state of its caller without taking it from the stack.

Be careful: a called word can hide your locals by binding the same name, and a word that reads a name it never bound quietly gets the value from its caller instead of failing. Bugs that only show up when a word is called from one particular place usually come from this. If a word works at the prompt but not inside another word, check the local names first.

Allowed names

A name is any token that is not a number, a string or a bracket, so km>mi, quit-key? and >hex are all valid names. 2x is a name, while 2 is a number. Units have stricter rules.

Using a name that is not bound fails and undoes the line. The check happens when the word runs, not when it is defined, so a quote can mention a word that does not exist yet. If you define it later, the quote works:

[ helper 2 * ] :twice-helper
[ 21 ] :helper
twice-helper .      42
