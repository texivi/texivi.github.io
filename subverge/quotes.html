Subverge / Handbook

Quotes

A quote is code in square brackets that is pushed instead of run. [ 1 2 + ] does nothing until something runs it. A quote is also a list: omega has no separate list type, so [ 1 2 3 ] is a list of three numbers, and running it pushes them. The words that run quotes are described in flow.

Quotes as code

[ 1 2 + ]           pushes a quote
[ 1 2 + ] do        runs it, leaving 3

if, times, map and the other control words are ordinary words that take quotes and decide when to run them. A defined word is a quote with a name, and using the name runs the quote:

[ dup * ] :sq
'sq get             pushes the quote itself
'sq get do          the same as sq

Quotes can be nested as deeply as you like, and they are values like any other. You can store them in definitions, keep them in lists, pass them to words and get them back from words:

[ [ 2 * ] [ 1 + ] ] :steps
5 steps [ do ] each .           11

Quotes as lists

[ 1 2 + ] len .                 3
[ 1 2 + ] 2 at .                '+

Inside a quote, a word is stored under its name. When a list word hands out such an item, it turns it into a symbol, so [ 1 2 + ] 2 at gives '+ and does not run +. Definitions and local assignments come out the same way: [ :x ] first is 'x.

A list is written as a quote of values:

[ 1 "two" [ 3 ] 'four ]

Building lists

Word Effect
range a b -- l the integers from a up to b-1
list ... n -- l the top n values as a list
append l x -- list x added at the end
cat a b -- c two lists joined
reverse l -- list back to front
sort l -- list numbers or strings in order 
0 5 range                       [ 0 1 2 3 4 ]
1 2 3 3 list                    [ 1 2 3 ]
[ 1 2 ] 3 append                [ 1 2 3 ]
[ 1 ] [ 2 3 ] cat               [ 1 2 3 ]
[ 5 2 9 2 ] sort                [ 2 2 5 9 ]

range holds at most 100000 numbers, and it fails when b is below a. 0 0 range is the empty list.

Lists cannot be changed, and each of these words builds a new list. append copies the whole list, so building a long list one item at a time with append gets slow very quickly: the time grows with the square of the length. For more than a few thousand items, push the items onto the stack and pack them with depth list, or use map over a range.

sort takes a list of numbers (bignums included) or a list of strings. It fails for anything else, or for a mix. It is a stable merge sort, so items that are equal keep their order.

Reading lists

Word Effect
len l -- n the number of items
at l i -- x item i, counting from 0
first l -- x the first item
last l -- x the last item
rest l -- list everything after the first
spread l -- ... every item onto the stack
has l x -- 1/0 whether x is in the list
index l x -- i where x first appears, or -1

at fails for a position past either end, and first and last fail on an empty list. rest of an empty list is the empty list.

has and index compare integers by value and strings by content. They compare every other value, including bignums and quotes, by identity, so [ [ 1 ] ] [ 1 ] has is 0: the two [ 1 ] are different objects.

Computing over lists

Word Effect
each l q -- runs q with each item pushed
map l q -- list the results of q on each item
filter l q -- list the items for which q leaves a true value
sum l -- n all items added
fold l x q -- y q applied to x and each item in turn 
[ 1 2 3 ] [ . ] each                    prints 1, 2, 3
[ 1 2 3 ] [ dup * ] map                 [ 1 4 9 ]
1 11 range [ 2 mod 0 = ] filter         [ 2 4 6 8 10 ]
[ 1 2 3 4 ] sum                         10
[ 1 2 3 4 ] 1 [ * ] fold                24
[ "a" "b" ] "" [ swap cat ] fold        "ba"

The quote that map runs must leave exactly one value for each item, or map fails. The quote that filter runs must leave a number, and the items for which it is not zero are kept. each also works on a string, and pushes each byte.

sum adds with +, so it works on bignums and ordinals: omega 1 2 list sum is ω+1. If you wrote [ omega 1 ] instead, you would get a list that holds the symbol 'omega, because words inside a list stay words. The sum of an empty list is 0.

fold keeps a running result. It starts as x, and for each item q runs with the running result and the item on the stack and leaves the new running result. fold is written in omega with the locals l, acc and q. Locals are dynamically scoped, so a quote that you pass to fold and that uses those three names as its own will see the ones from fold instead (names). Rename them in your quote or use each.

All of these check for Ctrl-C between items, and all of them stop at the first item that fails.

Lists of lists

Nested lists work as records and tables:

[ [ "ann" 31 ] [ "bob" 27 ] ] :people
people [ first ] map                    [ "ann" "bob" ]
people [ 1 at 30 > ] filter             [ [ "ann" 31 ] ]
people [ spread { name age } name say ] each

pci, memmap, drives and tab give their results in this form (machine).

Limits

One pair of brackets can hold 256 items as you type them, and brackets can be nested 32 deep. Lists that are built while a program runs have no such limit. Brackets that do not match make the whole line fail before anything runs (errors).
