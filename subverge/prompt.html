Subverge / Handbook

Prompt

The "prompt" is the » where you type omega code. Each tab has it's own prompt, its own history of earlier lines and its own queue of keys. What you type runs as one transaction when you press Enter.

What the prompt shows

In front of the », the prompt prints the stack of the tab in grey, from bottom to top:

1 2 [ dup * ] »

An empty stack prints nothing in front of the ». A long stack is cut on the left and shown with .. in front, so the top of the stack, which is what the next word will see, is always visible.

The stack that is shown is the committed one. While a line is running, nothing is printed until it finishes.

Editing keys

You edit a line at the prompt with Control and Alt keys. The full table is on the keys page. These are the ones used most:

Key Action
RET runs the line
C-a, C-e move to the start or end of the line
C-b, C-f, M-b, M-f move by character or by word
DEL, C-d delete before or at the cursor
C-k, C-u, C-w kill to the end, to the start or the last word
C-y, M-y yank the last kill, or an older one
C-p, C-n step through earlier lines
C-r, C-s search the earlier lines
C-_ undoes the last change to the line
TAB completes the name before the cursor
M-x runs a word by name
C-c, C-g throws the line away and starts a new one
F1 to F4, Alt-1 to Alt-4 switch tab

The arrow keys, Home, End and Delete move and delete as you would expect. Characters are inserted at the cursor, so you can fix a typo in the middle of a line without typing the rest again.

M-x asks for a word on a new line, with completion, runs it as if you had typed it, and brings the prompt back with the line you were editing. C-h starts the help keys, such as C-h k, which tells you what a key does. You can bind keys of your own; see keys.

The kill ring

C-k, C-u, C-w, M-d and M-DEL kill text, which means they delete it and keep it on the kill ring. The ring holds the last eight pieces and is shared by every tab, so text killed in one tab can be yanked in another. C-y inserts the newest piece at the cursor. M-y, typed right after C-y or another M-y, replaces what was yanked with the next older piece.

When a kill follows another kill with no other key in between, the text is added to the same piece. Forward kills such as C-k and M-d add at the end, and backward kills such as C-u, C-w and M-DEL add at the start. This is why typing M-d three times and then C-y brings back three words in their original order.

Undo

C-_ undoes the last change to the line. It keeps the last 16 states of the line, and a run of typed letters counts as one change, so typing a word and pressing C-_ removes the word. A kill, a yank, a completion and a recalled line are one change each. Ctrl-/ does the same as C-_.

Searching the history

C-r starts a search backward through the last 16 lines of the tab, and C-s starts one forward from the oldest. The prompt shows the text you have typed and the line that matches it. Typing more narrows the match, DEL shortens the text, and C-r or C-s moves to the next match in that direction. C-g puts the line back as it was. Any other key ends the search and leaves the matching line in the editor, and RET does the same without running the line.

Where the keys work

The editing keys work wherever a line is read: at the prompt, in the lessons of learn, in ask and calc, and in the questions of the viewer, the editor and dired. A few keys need the real prompt of a tab, because they run words or redraw it:

Keys At the prompt Everywhere else
M-x, C-h and your bindings yes no
C-l yes no
TAB completion yes, and in the M-x question no

Completion

Tab completes the name that ends at the cursor. The choices are the definitions of your tab, the words of root and the built-in words.

  • With one match, Tab writes the rest of the name and a space.
  • With several matches that begin the same way, Tab extends the name as far as they agree: them becomes theme, the part that theme, theme@ and themes have in common.
  • Otherwise Tab writes the first match in alphabetical order, and each further Tab replaces it with the next one, going around again at the end: ro gives root, rot, row, then root again.

A ', : or -> in front of the name is kept, so 'th completes to 'theme, 'themes and 'theme@ in turn. Locals are not offered, because they only exist while code runs.

ask and calc do not complete.

Line length

A line holds up to 200 characters, or less when the prompt itself is wide, because the line has to fit on one screen row after the stack and the ». When it is full, further keys are ignored. If the stack takes up a lot of the row, empty or a few drops give the line more room.

Code that is longer than one line belongs in a definition, which you write with 'name edit in scrawl, or in a root unit.

History

Up and Down, or C-p and C-n, step through the last 16 lines typed in the tab. C-r searches them for text. Empty lines, and a line that is the same as the one before it, are not added. The history belongs to the tab, is not saved to disk, and holds text only: recalling a line and pressing Enter runs it again, which is different from undoing it with back.

Characters you can type

You can type only printable ASCII, from space to ~. omega has a few values that print with other characters, such as ω and ℵ₀. The system draws them by redefining unused characters of the VGA font (screen). To use them:

omega .                      ω
aleph0 .                     ℵ₀
"\w and \A" say              ω and ℵ

\w and \A work inside any string. The words omega and aleph0 push the values themselves (ordinals, cardinals).

When a line fails

A line that fails prints its error in red, indented under the line, and the prompt comes back with the same stack as before:

1 2 » 3 0 /
  ! division by zero
1 2 »

Keys pressed while the failing line was running are thrown away, so the next prompt starts clean. See errors.

When a line runs for a long time

The prompt does not come back until the line finishes. C-c, or C-g, interrupts the line with the error interrupted, which also undoes it. If the line does not answer Ctrl-C, switch to another tab with F1 to F4 or Alt-1 to Alt-4. The other tabs keep running and their prompts keep working (tabs).

Programs that read keys

Programs that you start from the prompt, such as snake or top, read keys from the same queue. When they end, the prompt returns. ask prints a question and reads one line with the same editing keys, but without history:

"name? " ask say

Help pages

docs opens the help pages, and "name" doc opens one page. You can select a line of code in a page with Tab and run it with Enter, which closes the viewer and runs the line at the prompt (help).
