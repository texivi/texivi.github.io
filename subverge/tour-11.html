Subverge / Handbook

Part 11: Programs

The programs that come with Subverge are omega, and each one is a word in root. Press Ctrl-M for the menu of programs.

Games: snake, tiles, pong, life

Animations: rain, stars, bounce, sorting, mandel

Tools: calc, clock, stopwatch, todo, convert

Open a program to see how it works:

'snake open

Leave the editor with C-x C-c.

A program is a word that can read keys with key and draw with put and text. Games shows the shape they share, and apps explains how to add a program to the menu.

The demo index lists every program.
