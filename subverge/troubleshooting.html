Subverge / Handbook

Troubleshooting

This page lists problems you may run into and says what to do about each one.

Using it

The mouse does not move. A click inside the QEMU window gives it the pointer and Ctrl-Alt-G takes it back. mouse? is 0 when no PS/2 mouse was found (ps2). Every mouse action has a key (keys).

gfx says there is no Bochs display. The display is not the standard VGA card of QEMU. Start QEMU with -vga std (screen).

The clock is wrong. The tab bar shows the CMOS clock, and QEMU sets that clock to UTC by default. -rtc base=localtime on the QEMU command line shows local time.

No drives are found. The disk is attached as virtio or NVMe, and Subverge has only an IDE driver. Attach it with -hda.

Nothing is saved. The system is the live ISO, which keeps everything in memory. sys shows which system is running. install keeps the work.

A whole line did nothing. A word on the line failed, so the line was undone, including the parts that ran before the failure. The red text names the word and the reason (transactions).

back went further than expected. back counts only lines that changed something. A line that only printed, such as help, is skipped, and back goes to the line before it (back).

A word works at the prompt but not inside another word. Locals are dynamically scoped. A local of the calling word can hide a word with the same name, or the called word can read a local that was not meant to be passed. Renaming one of them fixes both cases (names).

forget says the name is not defined in this tab. forget removes only definitions made in the current tab. A word defined in root is changed in root with 'name open (names).

A root edit had no effect. The edit did not build, so root stayed as it was and the edit was kept as a draft. root marks the unit (draft). 'name open shows the error (root).

edit on top changed nothing in the other tabs. edit redefines a word in the current tab only, as a private copy that hides the root version. 'top open changes root for every tab and 'top forget drops the private copy (scrawl).

A program is missing from apps. apps prints a fixed list. 'apps open adds a program to it (apps).

The colours are unreadable. 'dusk theme switches back, and themes lists the others (themes). In amber, phosphor and haelide every colour is a shade of one hue, so programs that rely on colour are harder to read.

rgb colours are gone after a reboot. rgb changes the palette until the next theme switch or reboot and is not saved. rgb lines in startup apply at every boot (themes).

The theme resets at every boot. The live ISO always starts with dusk. An installed system keeps the theme.

sys shows the cat after a logo was picked. Either the theme changed and the logo carried the name of the old theme, or the logo was defined in another tab. sys runs in tab 1 at boot, so the logo belongs in a root unit (logos).

Tab does nothing at the prompt. Nothing matches the name before the cursor, or the cursor is right after a space (prompt).

redo has nothing to redo. A line changed the world after the back, which clears the redo list (back).

Ctrl-C does not stop the code. The code is in a place that does not check for Ctrl-C, such as a long built-in. F1 to F4 switch to another tab, which keeps working (tabs).

Everything froze. Something overwrote memory that the kernel uses, a port write hung the machine, or halt ran. Closing QEMU and starting it again recovers. An installed disk has saved every line up to the last one that succeeded.
