Part 7: Editing a program

'name edit opens the editor, scrawl, on a word. Type the program and save with C-x C-s, then quit with C-x C-c:

'countdown edit

Type this:

{ n }
n 0 > [
  n .
  30 sleep
  n 1 - countdown
] when

Then run it:

5 countdown

The word calls itself, takes it is argument as the local n and stops when n reaches 0.

The programs in root are edited the same way, with open. An edit takes effect only if it builds, so a mistake cannot break the running system:

'clock open

Leave the editor with C-x C-c. The old version stays in use if the edit did not build.

See scrawl, root and units.
