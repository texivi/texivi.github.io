Command Line Overview

This page explains how the prompt works. Every line you type is read when you press Enter, and it runs at once. You do not need to write a main. A definition goes into the world of the tab and stays until you remove it.

2 3 + .

A word comes after its arguments, so + comes after the numbers it adds. The stack is printed in grey in front of the », so you can see what the next word will get:

5 »

A bare name runs it:

Looking for a word

"sort" apropos

lists every word whose name or description mentions sort. Tab completes a name (prompt). words lists what you have defined in the shell, and root lists the programs that come with the system.

Undoing

A line that fails changes nothing. A line that worked can be undone:

1 2 3
back
redo

back undoes the last line and redo undoes the back, up to 64 lines each way (back, transactions).

Definitions

[ dup * ] :sq
7 sq .

The quote on the left becomes the word sq in this shell. A definition in the shell hides a root word of the same name in that shell only (names). To make a word available in every shell, put it in a root unit with 'name open.

Code that spans lines

A line holds up to 200 characters. Longer programs belong in scrawl:

'newword open

opens an editor on the word, and saving builds it. On an installed disk, words defined in a shell are saved with the shell, and edits to root are saved with root (saving).

Running things

Programs are words, so they run like words:

snake
90 timer
0xB8000 hexview

You can select a line of code in a help page with Tab and run it with Enter, which closes the viewer and runs the line at the prompt. docs opens the index of pages.

Stopping

Ctrl-C stops the line that the shell is running and undoes it. If the shell does not answer, move to another one with F1 to F4 or Alt-1 to Alt-4. The others keep running.

More

Prompt covers the editing keys and the limit on a line. Stack, quotes, names, flow, strings and numbers describe the language. First steps is a short session, and tour is the same session typed out for you.
