Subverge / Handbook

First steps

The welcome screen

The first shell shows the system information and the first-boot questions after booting, then the prompt:

»

» is the omega prompt. Each line typed there is an omega program, and it runs when Enter is pressed. Tabs 2 to 4 start at the same prompt. F1 to F4 and Alt-1 to Alt-4 switch between them.

Reading the pages

The help pages are part of the system. docs opens the index and "first-steps" doc opens a page by name. In the viewer, Up, Down, PgUp, PgDn, Home and End scroll, Space pages down, Tab selects the next link, Enter follows it and Backspace goes back. q and Esc leave. Enter on a line of code closes the viewer and runs the line at the prompt. With a mouse, a click follows a link or runs a code line, the wheel scrolls and a right click goes back (help, keys).

The first-boot questions ask whether to install and whether to take the tour, a twelve page walk through the system that types it is own lines. The rest of this page assumes n for both.

The stack

omega is a stack language. Values are pushed onto a stack, and words take their arguments from it and push their results back:

2 3 +

leaves 5 on the stack. The prompt shows the stack in grey before the »:

5 »

. prints the top value and removes it:

5 » .
5
»

Arguments come first and the operation last, as in Forth or an RPN calculator. Evaluation goes strictly left to right:

2 3 + 4 *                   20
2 3 4 * +                   14

dup, drop, swap, over, rot and nip rearrange values (stack). empty clears the whole stack.

Defining words

A quote is code in square brackets that is not run yet. :name takes the value on top of the stack and gives it a name:

[ dup * ] :sq
7 sq .                      49

sq works like a built-in word in this tab. see shows a definition and words lists the definitions of the tab:

'sq see
words

The quote mark in 'sq passes the name instead of running it. names covers definitions, locals and name lookup.

Undoing mistakes

Each line is a transaction. If any word in it fails, the whole line is undone and the stack and definitions are as they were before:

1 2 3
[ 7 ] :seven 4 5 0 /
  ! division by zero

The stack is still 1 2 3 and seven is not defined. See transactions.

Lines that succeeded can be undone as well:

[ 1 + ] :inc2
back
  rewound 1

back undoes up to 64 lines (back). Ctrl-C stops a line that runs too long.

Control flow

Conditions and loops take quotes:

5 3 > [ "bigger" say ] [ "smaller" say ] if
10 [ "hi" say ] times
0 5 [ . ] for               prints 0 to 4
3 [ dup 0 > ] [ dup . 1 - ] while drop      prints 3 2 1

The rest is in flow.

Lists

A quote is also a list:

0 5 range .                 [ 0 1 2 3 4 ]
[ 1 2 3 ] [ sq ] map .      [ 1 4 9 ]
[ 1 2 3 4 ] [ 2 mod 0 = ] filter .     [ 2 4 ]
[ 3 1 2 ] len .             3

Strings

"subverge" upper say        SUBVERGE
"a,b,c" "," split .         [ "a" "b" "c" ]
"x = " 42 str cat say       x = 42

The rest is in strings.

Big numbers and infinity

Integers that do not fit in 64 bits become bignums. omega, the first infinite ordinal, is a value as well:

2 100 ^ .                   1267650600228229401496703205376
omega 1 + .                 ω+1
1 omega + .                 ω

See numbers and ordinals.

A small program

A word that spans several lines is written in the editor:

'countdown edit

In scrawl:

{ n }
n 0 > [
  n .
  30 sleep
  n 1 - countdown
] when

C-x C-s saves and C-x C-c quits. Then:

5 countdown

counts down from 5, a little over three numbers a second. The word calls itself, takes its argument as the local n and stops when n reaches 0.

Tabs

F2 switches to tab 2, a seperate session with its own stack. sq is not defined there until it is defined again:

7 sq .                      49, because root has its own sq
'countdown defined? .       0

Definitions made at a prompt stay in their tab. Root words such as sq, apps and clock work in every tab. F1 returns to tab 1 (tabs). Super-Enter shows two tabs at once, and C-x 3 opens a window beside the current one. C-x o moves to the other window and C-x 1 returns to a single window.

Editing a line

The prompt edits a line with Control and Alt keys. C-a and C-e go to the start and the end of the line, M-b and M-f move over words, C-k kills the rest of the line, C-y yanks it back and C-_ undoes. C-r searches earlier lines and TAB completes a name. M-x runs a word by name and C-h k describes a key. The whole list is on the key map, and the lessons of learn from number 46 on teach it one key at a time.

Programs

apps lists the programs, and a program runs when its name is typed at the prompt. A program uses the whole tab until it ends. Ctrl-C or the quit key of the program stops it, and the other tabs keep running meanwhile.

"credits" doc

doc opens a help page.

The look

'amber theme                amber text on black
'dusk theme                 back to the default
sys                         the logo and system information again

See themes and logos.

Finding your way around

help                every built-in word, by group
'flow help          one group
'times help         one word
apps                the programs that come with Subverge
root                the root units and what they define
learn               the tutorial

learn teaches the language in short lessons with exercises (learn). omega describes the language, and tools, games and demos describe the bundled programs.

Keeping your work

The live ISO loses everything when the machine stops. install writes Subverge to a drive, and an installed system saves each tab after every line that changes it (saving).

Where to go from here

learn covers the language and the tour walks through the system. themes lists the themes and tips collects the details that are easy to miss.
