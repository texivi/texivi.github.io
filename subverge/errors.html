Subverge / Handbook

Errors

A failing word prints its message in red after a !, and the whole line is undone (transactions). This page describes the kinds of errors and what usually causes them. The exact wording can change between versions, so the page does not quote it.

Things that explain themselves

Some errors say plainly what is wrong: dividing by zero, taking an item from an empty list, asking for a position outside a list, brackets or strings that are never closed, a closing bracket with no opening one, a name that is not defined, a full stack, a power that is not allowed, and similar mistakes. Read the message and fix the line.

Things that need a note

An error that is raised with fail shows the text the program gave it. A message that you cannot find in these pages probably comes from the program's own check (catching).

  • Too few values on the stack. A value was used up earlier, or never pushed. 'word help shows what the word expects.
  • A word wants a number. Usually the arguments are in the wrong order, as in [ body ] 10 times instead of 10 [ body ] times.
  • A value of the wrong type. "5" 1 + fails where "5" >num 1 + works, and cat does not join a string to a list.
  • A string that is not a number. >num does not skip spaces.
  • map with a quote that leaves the wrong number of values. The quote must leave exactly one value for each item. Use filter to drop items.
  • Too many local names. More than 256 locals were alive at once, almost always because a recursive word binds locals at every level (flow).
  • Nested too deep. Usually a recursive word that never reaches its base case.
  • A name that is not defined in this tab. forget removes only the definitions of your own tab (names).
  • No help for a word. Your own words have no help entries (help).
  • A bignum where a machine integer is needed. Words such as times, at, peek and the bitwise words need numbers that fit in 64 bits (numbers).
  • A number that is too big. The result would have more than about 19,700 digits.
  • A bignum mixed with an ordinal in the wrong order. A bignum on the right of ordinal arithmetic, as in omega 2 100 ^ +, is refused. On the left it is absorbed, so 2 100 ^ omega + is omega.
  • A structure over one of the limits. A range, a split, a quote or a nesting of brackets can be too large.
  • A value that cannot go on the stack. Ordinary omega code cannot cause this, so it is a bug in Subverge.
  • A theme that does not exist. theme takes the name of one of the built-in themes as a symbol, as in 'raw theme. You cannot define themes in omega (themes).
  • Sorting the wrong things. sort orders numbers (bignums included) or strings, and every item must be the same kind. To sort records, map the list to keys first.

Infinity

  • An ordinal coefficient that is too big. The coefficient of an ordinal grew past 2^64, as in omega 4294967296 * 4294967296 *. Coefficients are machine integers, not bignums (how infinity works).
  • Operations that infinite values do not support. Ordinals and cardinals support only +, * and ^. There is no subtraction or division (ordinals).
  • A negative number in ordinal arithmetic. Ordinals are never negative, so omega -3 + fails.
  • Mixing cardinals with other values. Ordinals and cardinals cannot be combined directly. Convert the ordinal with card first.
  • A cardinal power that cannot be computed or written out.
  • A comparison that depends on the continuum hypothesis. It cannot be decided in ZFC, the usual foundation of mathematics (cardinals).

Screen

  • A help page that does not exist. "foo" doc named a page that is not in the system. Pages are named after their files, such as prompt, and a-to-z lists them (help).
  • Drawing before graphics mode is on. dot and box need gfx first (screen).
  • Too many bitmaps. Sixteen bitmaps exist already, and bmp-free gives one back (pictures).
  • Not a bitmap. A word that works on a bitmap was given a number that bitmap or picture did not return, or the bitmap was already freed.
  • A picture that does not exist. "foo" picture named a picture that is not built in, and pictures lists them (pictures).
  • A picture that cannot be read. The JPEG data is cut off or wrong, uses an unsupported kind of JPEG, or there is not enough memory.
  • No graphics display. gfx was used on a display that does not have the Bochs registers. Start QEMU with -vga std (screen).

Root

  • A word that is not in any root unit. open and src work only on root words. Use edit for the definitions of a tab (root).
  • An edit that did not build. Root stays as it was, and your edit is kept as a draft (root).

The JIT

  • A quote that cannot be compiled, or has no machine code yet. The JIT either cannot compile the quote or has not done it yet. Run it twice, or use compile.

Disks

  • A kernel that does not fit its slot. This only happens with a much larger custom kernel (disk layout).
  • A failed write to the drive. In QEMU this usually means a read-only image, or a full disk on the host.

Faults

If the processor reports a fault, the system tells you which one and says that your last line was dropped. The tab restarts with its world as it was (scheduler).
