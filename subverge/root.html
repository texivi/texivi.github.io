Subverge / Handbook

Root

Root holds the omega programs that come with Subverge, and you can edit it while the system runs. Words that every tab should have belong here too. An edit only goes live if it builds, so a mistake cannot break root.

Units

Root is split into units, one for each file in root/, and each starts with #>> name. They run in order at boot, so a unit can use anything defined before it. root lists them:

Editing a unit

'top open

opens the unit that defines top in scrawl. Nothing changes until you close the editor.

When you close the editor, the unit you edited and every unit after it are run again on top of the earlier ones. If they all build, the new root replaces the old one at once, every tab sees it, and it is saved. If anything fails, root stays as it was:

root unchanged, top: foo isn't defined (your edit is kept: open it again)

Your edit is kept as a draft, which root marks with (draft), and the next 'top open opens it again so you can fix it. back does not affect root.

Shadowing

A unit can redefine a built-in word. When that happens, the rebuild prints a warning with the names, in orange.

Saved root fails to build

This usually happens after an upgrade of the system. Subverge then reports this and boots with the root that is inside the kernel. The saved root is kept until your next root edit overwrites it.

To add your own, see units, and to list a program in apps, see apps.
