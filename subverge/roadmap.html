Subverge / Handbook

Roadmap

The "roadmap" lists what each release added and what is planned next. A ticked item is done. Planned items are plans, not promises.

Subverge 0.9.6

  • Editing keys at the prompt, in the pager and in scrawl, with bind, unbind, bindings and describe-key (keys)
  • M-x and the C-h help keys
  • Windows: up to four tabs on the screen at once, opened with Super-Enter or C-x 3 and C-x 2
  • phi, a tree of sets for named values, and dired
  • golden, and screenshots in the gallery
  • 39 more lessons in learn and seven more parts of the tour
  • A page for Terry A. Davis in credits
  • Room for a kernel of 4 MiB on an installed disk

Subverge 0.9.5

  • Pictures: bitmap and the bmp- words, picture and pictures, a JPEG decoder in the kernel
  • gallery, which shows the built-in pictures, and credits
  • Graphics mode in 24-bit colour
  • The kernel loads past 576 KiB from an installed disk

Subverge 0.9.4

  • The help pages inside the system, read with docs and doc
  • A PS/2 mouse on the text screen, with mouse and mouse?
  • Words for the infinity pages: pair, unpair, fusc, rational, hotel, rationals, collatz, thue, prime? and ulam

Subverge 0.9.3

  • text draws in graphics mode
  • window draws a titled window frame

Subverge 0.9.2

  • beep, for the PC speaker
  • Graphics mode with gfx, gfx-off, dot, box and window

Subverge 0.9.1

  • The haelide theme
  • Logos for sys, with logo, logos and logo@
  • type and fail

Subverge 0.9.0

  • Themes: dusk, raw, paper, amber and phosphor, remembered on installed disks
  • rgb for changing single colours
  • Bright background colours
  • redo
  • Tab completion at the prompt
  • apropos
  • Text words: lower, trim, starts?, ends?, replace, join
  • List words: reverse, sort, sum, fold, index
  • sqrt and gcd, for bignums too
  • pick, tuck and 2dup
  • cal, month and date
  • tiles
  • Go to line and duplicate line in scrawl

Subverge 0.8.0

  • Bignums up to 2^65536
  • Compiled code switches to bignums on overflow
  • Bignums in comparisons, conditions, str, >num, min, max and saved worlds
  • 0b binary literals
  • More learn lessons

Planned

  • UEFI booting
  • USB keyboards
  • SATA disks over AHCI
  • Networking
  • Sound
  • Multiple CPU cores
  • Floating point numbers
  • Support for real hardware
