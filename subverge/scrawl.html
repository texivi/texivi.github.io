Subverge / Handbook

scrawl

scrawl is the text editor. It is used for anything longer than one line: definitions, root units and new programs. It has no modes, so typing always inserts text, and the commands are Ctrl and Alt keys, the same ones as at the prompt (keys).

Opening it

You never start scrawl directly. It is opened by one of three words, and the word decides what happens to the text when you quit:

'sq edit            a definition in this tab
'top open           the root unit that defines top
"mine" unit         a new, empty root unit

edit works on the world of your tab, and open and unit work on root.

While scrawl is open, the title of the tab is edit followed by the name, and the tab is busy. The other tabs keep running, and each tab can have its own scrawl open.

The screen

The top row shows scrawl, the name that is being edited, [+] when there are unsaved changes, and the line and column of the cursor on the right. Each line of text has its number in the left margin, and rows after the end of the text show ~. The bottom row lists the main keys, and it is replaced by short messages, for example after a save, a failed search or setting the mark.

Lines that are longer than the screen scroll sideways as the cursor moves along them.

Keys

C-y yanks the last kill

M-g goes to a line number

You can type only printable ASCII, as at the prompt. Use \w and \A in strings for the omega and aleph symbols.

Killing and yanking

Text that you kill goes into the kill buffer of the tab, replacing what was there, and C-y puts it back at the cursor. Kills that follow each other with nothing in between are added to the same piece, so C-k twice at the start of a line takes the line and its line break. A kill can cover several lines, so you can move a block by marking it, killing it with C-w and yanking it where it belongs.

C-SPC sets the mark where the cursor is. The "region" is the text between the mark and the cursor. C-w kills the region, and M-w copies it without removing anything. Both clear the mark afterwards. C-x C-x puts the cursor at the mark and the mark where the cursor was, which shows you where the region starts.

The kill buffer belongs to the tab and stays between editing sessions, so text that you killed in one definition can be yanked into another.

Lines

M-g asks for a line number on the bottom row and moves to the start of that line. A number past the end goes to the last line, and ESC cancels. These are the numbers shown in the margin, so you can go straight to a line that an error message names.

Searching

C-s asks for text on the bottom row. RET searches forward from just after the cursor, goes around past the end if needed, and moves the cursor to the first match. ESC and C-g cancel. An empty answer repeats the last search, so C-s RET steps through every match. C-r does the same toward the start of the text. The search is case-sensitive.

Saving and quitting

C-x C-s records the current text as the saved version. Nothing outside the editor changes yet. C-x C-c, or C-q, quits, and what happens next depends on how scrawl was opened. It uses the last saved version:

  • edit parses the text and redefines the word in your tab.
  • open and unit rebuild root from that unit onward. If the rebuild fails, root keeps working as before and your text is kept as a draft (how root builds).

If the text has unsaved changes, the first quit warns you, and a second quit leaves without them. If you quit without ever saving, nothing changes.

edit in detail

'name edit opens the body of a definition, without its outer brackets:

[ { a b } a a * b b * + ] :hyp
'hyp edit

shows { a b } a a * b b * +. When you quit, the text is parsed back into a quote and defined as hyp in your tab. A few things follow from this:

  • A new name opens an empty editor, and quitting defines the word. Use it for anything longer than one line.
  • A root word opens its root definition, and quitting defines a private copy in your tab that hides the root one. Use open to change root itself.
  • A value that is not a quote, such as a string, opens as plain text and is saved back as a string.
  • Text that does not parse, for example text with a bracket that is never closed, is kept as a string, and scrawl reports the reason. The word then pushes that string when it runs. Open it again with edit to fix it.

Because edit redefines the word, the change is an ordinary change to the world: back undoes it, and on an installed disk it is saved.

Comments do not survive edit. The text is parsed into a quote, and printing the quote back for the next edit gives the code without them. Code whose comments matter belongs in a root unit, where the source is kept as you wrote it.

Size

edit shows at most 16 KiB of the text of a definition. Root units have no limit of their own, apart from the 1 MiB slot in which all of root is saved.

On the screen

scrawl uses the whole window of its tab, which is 80 by 24 characters when the tab has the screen to itself, and smaller in a split window. The mouse is not used in the editor. The tab keys F1 to F4 and Alt-1 to Alt-4 still switch tabs, so another tab can show a help page while you write a unit.
