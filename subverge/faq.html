Subverge / Handbook

FAQ

General

Is Subverge a Linux distribution?

No. The kernel, ordinal, was written for Subverge, and so were the bootloader, the shell, the editor and every program. Subverge is built on Linux with gcc and nasm, but nothing of Linux is in the ISO except GRUB, which only boots the live system.

Is it a TempleOS fork?

No. It took two ideas from TempleOS, a shell that is also the compiler and ring 0 for everything, and none of it is code. The language, the kernel and the undo of lines are different. See history.

Why is it called Subverge?

The name comes from subvert and diverge. See history.

Can it be used every day?

No. It runs in QEMU, has no network and no protection between programs, and a bad poke can take the machine down. See expectations.

Is there a roadmap?

See the roadmap.

Running it

Where are the files?

Subverge has no files. Definitions are in the world of a tab, programs are in root and named values such as notes are in phi. An installed disk saves all three.

Why was the work lost after a reboot?

The live ISO saves nothing. install puts Subverge on a drive, and an installed system saves after every line that succeeds, so at most the line being typed is lost.

A new ISO still shows the old sys

An installed disk was attached. The live system loads the root and the tabs saved on that disk, and the saved root has the old sys. The kernel and the built-in words are new. install on the same drive replaces the kernel and keeps the work.

Help pages

How are the help pages read?

docs opens the index and "name" doc opens a page. Tab selects the next link, Enter follows it, Backspace goes back and q or Esc leaves (where the pages live).

How do the shells switch?

F1 to F4 and Alt-1 to Alt-4 select shell 1 to 4. A click on a tab title in the top bar does the same. Super-Enter, C-x 3 and C-x 2 open windows to show several shells at once (tabs).

Which keys does the prompt use?

The prompt, the page viewer and the editor share C-a, C-e, C-k, C-y, M-f, C-s and the others. M-x runs a word by name and C-h asks about a key or a word. The key map lists all of them.

How is a key changed?

bind takes the name of a key and a quote and runs the quote when the key is typed at the prompt, as in "M-j" [ "dup " insert ] bind. A binding is saved with the world of the tab (keys).

What is phi?

A tree of sets that holds named values such as notes. The tabs share it and an installed disk saves it (phi).

The mouse does not move.

QEMU gives the mouse to the guest after the first click in its window, and Ctrl-Alt-G takes it back. mouse? is 1 when the system found a mouse. Every mouse action has a key as well (keys).

How are the colours changed?

themes lists the themes and 'paper theme switches to one. See themes.

The system

Is it POSIX compliant?

No. POSIX describes processes, files, file descriptors and system calls, and Subverge has none of them. Programs are omega words, and memory, I/O ports and PCI devices are reached with words such as peek, in and pci@. See omega for smarties.

Does it have its own bootloader?

Installed disks use the Subverge bootloader. The ISO uses GRUB.

Why does everything run in ring 0?

Every word at the prompt reads and writes the machine directly, as in TempleOS. Separating programs from the kernel would need user mode, system calls and paging per process, and Subverge omits that layer. Transactions undo most mistakes. Writes to the hardware are the exception.

Is it self-hosting?

No. Subverge has no C compiler or assembler, so the kernel is built on Linux. The programs in root are omega source and can be edited and rebuilt inside Subverge (root).

Is it multi-user?

No. The user name on the sys screen is a string, and 'user open changes it.

Can the colours be changed?

themes lists the themes and 'haelide theme switches to one. n r g b rgb changes one colour and logos lists the logos that sys can draw. See themes and logos.

Why is the screen so small?

Subverge uses 80 by 25 VGA text mode. The top row holds the tab bar, and a tab shares the screen with others when windows are open. gfx starts a 640 by 480 graphics mode with dots, boxes, text and titled frames. See screen.

Does it have networking or sound?

Sound comes from the PC speaker. beep plays a tone with a pitch and a length (ports). Other sound hardware and networking are on the roadmap.

The language

Why is the shell a programming language?

A command and a program are the same thing. A line typed at the prompt can be put in a quote, named and saved as a program. See omega.

Why is everything written backwards?

omega is postfix, so 2 3 + replaces 2 + 3. The arguments go on the stack first and the word that uses them comes last. This needs no brackets and no precedence rules. See stack.

Why are locals dynamically scoped?

A word can read the locals of its caller. This is occasionally useful and occasionally the source of surprising bugs. See names.

How big can a number get?

Up to 2^65536, about 19,700 digits. A larger result fails with an error (bignums). The infinite values omega and aleph0 are a different kind of value. They compare above every integer, and they are positions and sizes, not large integers (ordinals).

What is omega, the value?

omega pushes ω, the first position after all the natural numbers, which the shell is named after. Vsauce's How To Count Past Infinity covers the background. See ordinals.

Why does omega 1 - fail?

Ordinals support only +, * and ^. ω has no position directly before it, so ω−1 is not an ordinal. See ordinals.

Why did a whole line do nothing?

One of its words failed and the line was undone. See transactions and errors.

How is a line undone?

back undoes it. See back.

How is a program stopped?

Ctrl-C stops the code running in the current tab and undoes the line. A tab that does not respond can be left with F1 to F4 or Alt-1 to Alt-4. The tabs are scheduled seperately, so the others keep working (tabs).
