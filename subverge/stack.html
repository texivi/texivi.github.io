Subverge / Handbook

Stack

Each tab has one data stack of up to 1024 values. A word takes its arguments from the top of the stack and leaves its results there. In 2 3 +, the numbers 2 and 3 are pushed, and + replaces them with 5. Apart from locals (names), values pass between words only through the stack.

Effects

A "stack effect" lists what a word takes and what it leaves. The top of the stack is on the right:

dup     a -- a a
swap    a b -- b a
rot     a b c -- b c a

'word help shows the stack effect of any built-in or root word (help). The letters are only labels: n and i are numbers, s is a string, l is a list, q is code, and a, b and x can be anything.

Stack words

Word Effect
dup a -- a a copies the top value
drop a -- discards the top value
swap a b -- b a swaps the top two
over a b -- a b a copies the second to the top
rot a b c -- b c a moves the third to the top
nip a b -- b discards the second
tuck a b -- b a b copies the top under the second
2dup a b -- a b a b copies the top two
pick ... n -- ... x copies the value n below the top
depth -- n how many values there are
empty ... -- discards everything

0 pick is the same as dup and 1 pick is the same as over. pick can reach as deep as the stack goes. It fails when n is too big.

10 20 30 2 pick         10 20 30 10
1 2 tuck                2 1 2
3 4 2dup * rot rot +    12 7

Every stack word moves whole values, so copying a quote, a string or a bignum with dup costs the same as copying a small number. The copies share the same object (values and objects).

Juggling or locals

When you need to keep three or more values in play, locals are easier to read than rot and pick:

[ rot dup * rot dup * + swap dup * + ] :sumsq3
[ { a b c } a a * b b * + c c * + ] :sumsq3

Both define the sum of three squares. The first uses only the stack, so it is shorter and a little faster when compiled, because the JIT handles dup and * directly while locals go through the interpreter. The second is easier to read. It is common to mix them: use the stack for values that are used up at once, and locals for values you use more than once.

Whole-stack operations

depth list packs the whole stack into one list, and spread unpacks a list onto the stack. Together they let you save and restore the stack:

depth list { saved }
... code that makes a mess ...
empty saved spread

After depth list the stack is empty, so the code in the middle starts from nothing, and empty saved spread puts the old values back, whatever the code left. learn runs every exercise this way. To keep the values on the stack and also save a copy, put them straight back with depth list dup spread (catching).

To print the stack without changing it:

depth list dup . spread

The prompt already shows the stack in front of each », cut on the left when it is long.

Printing values

Word Pops Prints
. one value the value as source, then a newline: strings in quotes, symbols with '
say one value the value as text, then a newline: strings without quotes
write one value as text, without a newline

. is for looking at values, and say is for output that people read. "hi" . prints "hi", and "hi" say prints hi.

Errors

A word that finds too few values fails, and the message names the word. A word that finds the wrong kind of value fails in the same way. Either way the whole line is undone (transactions), so the stack is as it was before the line.

If you push a 1025th value, the line fails because the stack is full. This almost always means a loop that pushes on every round without taking anything off, such as 2000 [ 1 ] times.

The stack and the world

The stack is part of the world of the tab. It is saved on installed disks, restored by back and redo, and kept separate in each tab. Values that cannot be written as source code do not survive a reboot (saving).
