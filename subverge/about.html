Subverge / Handbook

About Subverge

Subverge is an x86-64 operating system written from scratch. It is a hobby project developed at github.com/texivi/Subverge, licensed under the GNU GPL v3, and it runs in QEMU. It has not been tried on any other machine.

The kernel is ordinal, the shell is omega and the editor is scrawl. The name subverge is a coinage from subvert and diverge. The history page has the origin of the names, the inspiration and the list of releases.

What the system consists of

The kernel is written in C and x86-64 assembly. ISOs boot through GRUB. Installed disks boot through a master boot record and a second stage that come with Subverge (boot). Everything above the kernel is omega source in root: the utilities, the games, the installer and the lessons of learn. The source is kept in the kernel image and is rebuilt when it is edited.

Part What it does
ordinal Memory, interrupts, the scheduler, drivers and the JIT.
help The pager for these pages and the PS/2 mouse driver.
omega The language: parser, interpreter, garbage collector, bignums and ordinals.
scrawl The text editor behind 'name edit and 'name open.
root The programs written in omega.
docs These pages, linked into the kernel (where the pages live).

The help

These pages are stored in the kernel image, so they match the running build and work on the live ISO. docs opens the index and "name" doc opens a page. The pager is part of the kernel and reads a small dialect of markdown. A table built together with the kernel maps page names to text, and no disk is read.
