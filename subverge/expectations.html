Subverge / Handbook

Expectations

Experiment

Subverge is a hobby operating system written by one person. It targets QEMU and has been tested only there. Releases change things, sometimes in ways that break saved roots. The roadmap lists what is planned, and none of it is promised.

Own system

Subverge has it is own kernel, shell and programs. An installed disk holds fixed slots (disk layout). The system has no processes, users or permissions. Everything written for it is an omega word, kept in a tab or in root and saved as omega source. Named values are kept in phi.

Programming

The documentation and learn assume that the reader already programs. They do not explain loops, variables or functions. Some knowledge of Forth or another stack language helps, and readers who know Forth should start with omega for Forth programmers. The ordinals and cardinals pages explain the mathematics they use. Vsauce's How To Count Past Infinity covers the background.

Breakage

Everything runs in ring 0, so a bad write to memory can take down the whole virtual machine. Most mistakes cost nothing, because a failing line is undone and back rewinds the last 64 lines. Writes to raw memory and to I/O ports cannot be undone. See omega for smarties.

Real disks

install erases the drive it is given, including the partition table. Use it only on a disk image made for the purpose. QEMU can pass a real disk to the guest, and Subverge installs onto it when asked. Read the drive list that install prints before typing yes.

Help

Run learn and read 'word help before asking how a word works. A question should include the exact line, the exact error and the expected result. See troubleshooting.

Releases

Releases carry no dates. The roadmap lists planned features.
