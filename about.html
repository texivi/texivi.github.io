About

I'm texivi. I build operating systems for fun and run Exherbo on my own machine. I use macOS as well, and I make apps for it.

My main project is Subverge, an OS I write in C and x86-64 assembly. The shell language it uses, omega, is mine too. Besides that I write a window manager and a text editor in C, a Mac app called Fluent in Swift, and mods for games in Lua.

I like TempleOS, Syllable and old desktops in general. When I'm not on those I'm usually playing Balatro, and I've made a few mods for it.

Whatever I learn about something usually turns into a post. If you want to talk, there's the contact page.
